Projects

Explore a curated selection of high-impact, technically rigorous builds — where embedded systems, real-time algorithms, and expressive design converge.

GestureInk – Real-Time Air Drawing with Hand Tracking, MQTT & Haptics

Frontend: Python, OpenCV, NumPy

Embedded: Arduino (C++), ESP32, MQTT

Frameworks: cvzone, MediaPipe

A gesture-controlled drawing system engineered for intuitive, contactless input. Developed at MakeUofT 2025, GestureInk leverages AI vision pipelines and custom glove sensors to convert hand movements into real-time digital strokes, with support for dynamic color switching and sub-150ms latency via MQTT-based IoT communication.

"GISelle" – Geographic Information System for Safe Routing and Emergency Access for Women

Backend: C++, STL, std::thread

Frontend: EZGL UI

Algorithms: A*, Trie, Multi-Destination Dijkstra, Simulated Annealing

A safety-first navigation system designed for vulnerable communities, GISelle reimagines routing through the lens of empathy and efficiency. Built in ECE297, it features optimized multi-drop delivery paths, responsive autocomplete search, and dark-mode UI, all accelerated by multi-threaded spatial algorithms and heuristic tuning.

Brain Tumor Detection from MRI Scans using Transfer Learning (Python, TensorFlow, Keras)

Backend: Python (TensorFlow, Keras)

Techniques: VGG16 Transfer Learning, Image Augmentation

Deployment: FastAPI, HTML/CSS

Developed a deep learning model to classify MRI brain scans into glioma, meningioma, pituitary tumor, or no tumor. Leveraged VGG16 pretrained on ImageNet, fine-tuned with custom dense layers and data augmentation. Achieved 97.5% training accuracy and F1-scores above 0.90 across all classes. Web deployment enables real-time tumor predictions.
